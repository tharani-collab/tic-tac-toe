# Tic Tac Toe

A two-player Tic Tac Toe game built with HTML, JavaScript and Tailwind CSS v4 using npm.

## Requirements
- Node.js and npm

## Setup
```bash
npm install
npm run dev
```

Keep the terminal running, then open `index.html` using VS Code Live Server.

## Production CSS
```bash
npm run build
```

This generates `output.css`.
